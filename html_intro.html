Introduction to HTML

HTML (HyperText Markup Language) is the foundation of every website — it defines the structure and content of a page. This lesson covers the basics before we move on to styling and behavior.

6 min read
Beginner
No prerequisites

01What is HTML?

HTML is a markup language, not a programming language — it describes what content is (a heading, a paragraph, an image) rather than how to compute something. A browser reads your HTML and renders it as a page.

Every HTML file is made of elements, written as tags like <p> or <h1>, that wrap your content and tell the browser what it means.

02Document Structure

Every HTML page starts with the same basic skeleton. Here's the minimum structure every document needs:

index.html
<!-- Tells the browser this is an HTML5 document -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
  </body>
</html>
Why the <head> and <body> split?

The <head> holds information about the page (title, metadata) that isn't shown directly. The <body> holds everything visible on the page.

03Elements & Tags

Most elements have an opening tag and a closing tag, with content in between:

  • <h1> – <h6> — headings, from most to least important
  • <p> — a paragraph of text
  • <a> — a link to another page
  • <img> — an image (a self-closing tag with no closing pair)
  • <div> — a generic container for grouping content

04Attributes

Attributes add extra information to a tag and always live inside the opening tag as name="value" pairs:

example.html
<a href="https://example.com" target="_blank">Visit site</a>

Here, href tells the link where to go, and target="_blank" tells the browser to open it in a new tab.

05Next Steps

That's the core of HTML — structure and meaning. Next, we'll style this structure with CSS to control color, layout, and spacing.
